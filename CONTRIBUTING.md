# Contributing

Bug reports and pull requests are welcome, especially from other e-ink tablet owners (Boox, Onyx, Supernote-class Android devices, reMarkable alternatives that run Android).

1. Build: see *Build from source* in the README. `./gradlew :app:testDebugUnitTest` must pass.
2. Keep the UI e-ink friendly: no animations, no ripples, high contrast, big touch targets, one refresh per action.
3. Test on a device in a scratch notebook, never in your real notes.
4. Say which tablet and Android version you tested on.
